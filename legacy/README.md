# Bản Node.js trước khi chuyển Java

Thư mục này giữ lại source, script và test của backend Node.js để đối chiếu và khôi phục. Nó không được Maven biên dịch và không được script chạy Java sử dụng. Các đường dẫn frontend trong tài liệu cũ là đường dẫn lịch sử.

Bản đang sử dụng: `src/main/java`, `src/main/webapp`, `scripts`, `db/migrations`.
